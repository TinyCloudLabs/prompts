<h1 id="set-up-tinycloud">Set up TinyCloud</h1>
<p>Keep your personal records, such as weight, workouts, goals and todos, in your own TinyCloud storage. Use the same link in ChatGPT, Claude, Claude Code, Codex or OpenCode.</p>
<p><strong>Paste this into your app or agent:</strong></p>
<blockquote>
<p>Set up TinyCloud using <a href="https://agents.tinycloud.xyz/connect">https://agents.tinycloud.xyz/connect</a></p>
</blockquote>
<p><strong>For the assistant:</strong> keep the owner&#39;s original request and continue it in this conversation. Use the route for the environment you are running in. In a chat app, a link to this page alone is a setup request; give that app&#39;s steps without asking what the owner wants to do. Do not ask the owner to choose a different link or file format.</p>
<h2 id="coding-agents">Coding agents</h2>
<p><strong>Claude Code, Codex and OpenCode on the owner&#39;s computer:</strong> fetch and read the <a href="https://agents.tinycloud.xyz/apps">original coding-agent setup guide</a> in full, then follow it exactly for the owner&#39;s original request. Fetch that guide yourself; do not ask the owner to paste another URL or repeat their request.</p>
<p>The original guide is the authority for all prerequisites, installation commands, permissions, sign-in, first-record behavior, troubleshooting and cleanup. This page does not replace or modify any of those instructions. Do not reconstruct the setup from a summary or use the chat-app MCP instructions below for this route.</p>
<p><strong>ChatGPT, Claude chat and other chat apps:</strong> use the instructions below instead. Do not run the coding-agent setup in a chat app&#39;s temporary code sandbox.</p>
<p>Jump to <a href="#chatgpt">ChatGPT</a>, <a href="#claude">Claude</a>, or <a href="#other-chat-apps">other chat apps</a>.</p>
<h2 id="chatgpt">ChatGPT</h2>
<p><strong>For ChatGPT assistants:</strong> if TinyCloud tools are not available yet, reply with only the four numbered steps below, in at most 120 words. No introduction, images, feature menu, plan or price caveats, extra sections, or closing questions. Do not send the owner back to this page to find the instructions. If the tools are already available, use them to continue the original request instead of repeating setup.</p>
<ol>
<li>In a browser, open <a href="https://chatgpt.com/plugins">ChatGPT Plugins</a> → <strong>+ → Add custom MCP server</strong>.</li>
<li>Enter <strong>Name:</strong> TinyCloud; <strong>Description:</strong> Personal records in TinyCloud; <strong>Server URL:</strong> <code>https://mcp.tinycloud.xyz/mcp</code>; <strong>Authentication:</strong> OAuth.</li>
<li>Review the warning, select <strong>Create as a plugin</strong>, sign in with OpenKey, and install it.</li>
<li>In a conversation, type <strong>@</strong>, select <strong>TinyCloud</strong>, and make your original request. For setup only, ask: <strong>“What personal apps do I already have in TinyCloud?”</strong></li>
</ol>
<p><strong>Troubleshooting only after a reported or observed blocker:</strong> do not infer that an account cannot connect from its plan name, generic availability documentation, or TinyCloud&#39;s absence from the app directory. Do not run an eligibility preflight or recommend an upgrade or developer mode speculatively. A successful connection takes precedence over a contrary documentation assumption. If the option is missing or an action is rejected, address that specific UI state or error briefly; ask one targeted question only if needed to choose the next action. Once enabled, follow <a href="#approve-access-and-continue">Approve access and continue</a> when the tools request approval, not as an extra initial setup section.</p>
<h2 id="claude">Claude</h2>
<p>Use the hosted MCP connector, not the local CLI. Its server URL is <strong><code>https://mcp.tinycloud.xyz/mcp</code></strong>, and its authentication is <strong>OAuth</strong> through OpenKey.</p>
<ol>
<li>On Claude web or Desktop, open <a href="https://claude.ai/customize/connectors">Customize → Connectors</a>, then <strong>+ Add → Add custom connector</strong>.</li>
<li>Name it <strong>TinyCloud</strong>, enter <strong><code>https://mcp.tinycloud.xyz/mcp</code></strong>, and continue. Review the detected OAuth settings and choose to sign in with OpenKey.</li>
<li>Finish adding the connector. In your conversation, use <strong>+ → Connectors</strong> to enable TinyCloud, then make your original request.</li>
<li>Follow <a href="#approve-access-and-continue">Approve access and continue</a> below. Once connected, you can also use it in Claude&#39;s mobile apps.</li>
</ol>
<p>For a managed workspace, an owner or administrator may need to add the connector first. See <a href="https://support.claude.com/en/articles/11175166-getting-started-with-custom-connectors-using-remote-mcp">Claude&#39;s custom-connector instructions</a>.</p>
<p>If you want to approve record-writing tools once rather than on every call, find <code>tinycloud_apps_write</code> in the connector&#39;s tool permissions and choose <strong>Always allow</strong>. Only do this if you trust it to write records without per-call confirmation. This does not replace the OpenKey access approval.</p>
<h2 id="other-chat-apps">Other chat apps</h2>
<p>If your app supports remote MCP over HTTP with OAuth, add <strong><code>https://mcp.tinycloud.xyz/mcp</code></strong>, choose <strong>OAuth</strong>, and sign in with OpenKey. Enable the connection for your conversation, then make your request. Mobile support depends on the app.</p>
<p>If the app has no custom remote MCP support, reading this page cannot add that capability. Say so and direct the owner to a supported ChatGPT web or Claude client. Do not suggest installing a CLI in a temporary chat sandbox as a substitute.</p>
<h2 id="approve-access-and-continue">Approve access and continue</h2>
<p>With TinyCloud enabled, make your original request, or ask: <strong>“What personal apps do I already have in TinyCloud?”</strong> The assistant will show the actual OpenKey connect or personal-record access link returned by a TinyCloud tool. Open it yourself, review the requested access, approve, then return to the conversation and tell the assistant to continue.</p>
<p><strong>For chat assistants:</strong> use the connected TinyCloud personal-app tools and the instructions they return. If the tools are not available yet, give the relevant connection steps above; do not claim setup is complete. Never ask the owner to paste a password, private key, access token, delegation or approval code into chat. For setup-only requests, follow the <a href="#setup-only-requests-in-chat-apps">default-record recipe</a> below, but perform the reads and writes through the connected tools, not the CLI. Read the saved record back before reporting success.</p>
<p>A brand-new account&#39;s storage can take a minute or two to finish setting up after the first approval. If a tool reports <code>SPACE_NOT_HOSTED</code>, tell the owner it is still being set up and retry with backoff for about two minutes. Do not ask for another or broader sign-in to fix it.</p>
<p>To disconnect a chat app, remove or disconnect TinyCloud in that app&#39;s plugin or connector settings. Disconnecting does not delete your stored records. Local CLI cleanup remains in the original <a href="https://agents.tinycloud.xyz/apps#undo">coding-agent guide&#39;s Undo section</a>.</p>
<h3 id="setup-only-requests-in-chat-apps">Setup-only requests in chat apps</h3>
<p>This record recipe is shared with the original guide. For chat apps, use the connected tools rather than its CLI or skill-command references.</p>
<p>If the owner only asked for setup or named no record, save one default record without asking, after sign-in is approved (skill §4) and not before: app <code>todos</code>, kind <code>todo</code>, key <code>xyz.tinycloud.agent-data/todos/todo/open/try-my-personal-apps</code>, value <code>{&quot;v&quot;:1,&quot;at&quot;:&quot;&lt;UTC&gt;&quot;,&quot;data&quot;:{&quot;title&quot;:&quot;Try my personal apps&quot;},&quot;by&quot;:&lt;client&gt;}</code>, where <code>&lt;UTC&gt;</code> is the clock&#39;s time from <code>date -u +%FT%TZ</code> (skill §1; run it again if it is more than 5 minutes old), never an estimate. If the <code>todos</code> app or its <code>todo</code> kind doesn&#39;t exist yet, write their catalog records first (skill §2 rule 2): <code>xyz.tinycloud.agent-data/catalog/todos</code> = <code>{&quot;app&quot;:&quot;todos&quot;,&quot;title&quot;:&quot;Todos&quot;,&quot;about&quot;:&quot;Things to do.&quot;,&quot;created&quot;:&quot;&lt;TODAY&gt;&quot;,&quot;by&quot;:&lt;client&gt;}</code> and <code>xyz.tinycloud.agent-data/catalog/todos/todo</code> = <code>{&quot;app&quot;:&quot;todos&quot;,&quot;kind&quot;:&quot;todo&quot;,&quot;about&quot;:&quot;One record per thing to do.&quot;,&quot;shape&quot;:&quot;item&quot;,&quot;states&quot;:[&quot;open&quot;,&quot;done&quot;],&quot;v&quot;:1,&quot;fields&quot;:{&quot;title&quot;:&quot;text: what to do&quot;}}</code>. Write commands are in skill §6. Get that key and its done twin <code>xyz.tinycloud.agent-data/todos/todo/done/try-my-personal-apps</code> first (skill §5), and skip saving if either exists, so a todo the owner already ticked off isn&#39;t saved again. Afterwards tell the owner the key, that “What’s on my todo list?” shows it, and that you&#39;ll delete it on request (the skill&#39;s <code>kv delete</code>, §6).</p>
